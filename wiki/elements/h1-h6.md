# `<h1>`〜`<h6>`

## 概要

`h1`〜`h6`は、AAPタグセットの見出し定義がCERN SGMLガイドを経て初期HTMLへ保持された、共通の直接史料を持つ6段階の見出し要素群である。

## 現在の意味

WHATWG HTML Living Standardでは、`h1`〜`h6`はそれぞれのセクションの見出しを表す。[HTML Living Standard](../../raw/html.spec.whatwg.org/multipage/sections.html)（[公開版](https://html.spec.whatwg.org/multipage/sections.html#the-h1,-h2,-h3,-h4,-h5,-and-h6-elements)、2026-08-09確認）

## HTMLへの導入

1992年のCERN公式HTML資料は`H1`〜`H6`の6段階を列挙し、CERN SGMLガイドで定義されたままHTMLへ保持したと説明する。[CERN, *Tags used in HTML*](../../raw/www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)（[公開元](https://www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)）

## HTML直前の祖先

HTML直前の祖先はCERN SGMLガイドの見出し要素群である。CERN資料が6段階を「定義どおり維持した」と明記するため、単なる同名存在ではなく集合単位の採用因果を確認できる。[CERN, *Tags used in HTML*](../../raw/www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)（[公開元](https://www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)）

## さらに上流の由来

### 証拠

CERN資料は見出し定義がAAPタグセットに由来すると明記する。1991年2月1日のRCS識別子を持つAAP Book DTD BK-1保存版は見出し要素群を`h|h1|h2|h3|h4`と宣言しており、AAP側に5要素の見出し語彙が実在したことを直接確認できる。ただし、AAPの5識別子とHTMLの6段階は一致しないため個別の番号対応は確定しない。1988年Waterloo SCRIPT GMLにも`H1`〜`H6`が存在するが、WaterlooからCERNまたはHTMLへの採用因果は確認できない。[AAP Book DTD](../../raw/ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/aapbook.dtd)（[公開元](https://ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/aapbook.dtd)） [CERN, *Tags used in HTML*](../../raw/www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)（[公開元](https://www.w3.org/History/19921103-hypertext/hypertext/WWW/MarkUp/Tags.html)） [Waterloo SCRIPT GML User’s Guide](../../raw/web.archive.org/web/20020504095301/http%3A/www.uga.edu/~ucns/stddocs/script-gmlref-tso.txt)（[公開元](https://web.archive.org/web/20020504095301/http://www.uga.edu/~ucns/stddocs/script-gmlref-tso.txt)）

SUNETアーカイブの`README`は、収録物をSAICの`actd.saic.com:pub/SGML/AAP`から匿名FTPで複製したと記録する。一方、`README.first`は収録DTDが最新リビジョンではないと明記するため、このBK-1保存版をAAP DTD全版の最終形とは扱わない。[AAP archive `README`](../../raw/ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/README)（[公開元](https://ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/README)） [AAP archive `README.first`](../../raw/ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/README.first)（[公開元](https://ftp.sunet.se/mirror/archive/ftp.sunet.se/pub/text-processing/sgml/AAP/README.first)）

### 解釈

出版SGMLで形式化された見出し階層がHTMLの見出し語彙の背景にある。ただし、一般的な紙の見出しからHTMLへ直接移植されたとはせず、AAPとCERN SGMLを経由する確認済みの集合単位の経路を記す。

## 系譜

AAPタグセット見出し → CERN SGMLガイド `H1`〜`H6` → 初期HTML `H1`〜`H6` → 現行HTML `<h1>`〜`<h6>`

## 確度

**A**

CERN SGMLからHTMLへの6段階の保持と、さらに遡ったAAPタグセット由来をCERN自身が明記するため。AAPから各HTML見出しへの個別番号対応ではなく、見出し要素群全体の因果を評価する。

## 否定された仮説

Waterlooに同名の`H1`〜`H6`が存在することだけから、Waterloo → CERN → HTMLという直接系譜を断定すること。確認できる因果はAAP → CERN SGML → HTMLである。
