HTML 3.0 Draft (Exprired!) Materials

HTML 3.0 has been superceded by HTML 3.2

Please see the HTML 3.2 Materials

In March of 1995, an HTML 3.0 specification was released. Based upon earlier work on HTML+, extends HTML 2.0 to support tables, text flow around figures and math. This document has expired. It is no longer being maintained.

The features proposed in this document are undergoing specification, review, and testing. See the W3C Activity Statement on HTML for more information.
