<ul><a name=1></a><h2>Tag reference, Part 1</h2></ul>

<P><A NAME="1165967"></A>This chapter contains an alphabetical listing
of all HTML tags supported in Navigator 3.0 and earlier. The tags are presented
in the following format: _IMG SRC="tags1a.gif" HEIGHT=419 WIDTH=512_</P>

<P><A NAME="1011905"></A>The following sections comprise an alphabetical
reference of all tags supported by Netscape Navigator 3.0 and earlier.</P>

<P>
<HR><A NAME="A (anchor or link)"></A><A NAME="1005210"></A></P>

<H2>A (anchor or link) </H2>

<P><A NAME="1005211"></A>The A tag lets you define anchors and links. </P>

<P><A NAME="A as anchor"></A><A NAME="1005212"></A></P>

<H3>A as anchor </H3>

<P><A NAME="1145057"></A>An anchor marks a section of an HTML document
and provides a way for links to connect that part of the document. The
A tag typically encloses text or images that represent an anchor, such
as a heading in a document or a logo. Navigator does not use any special
formatting to indicate that the text or image represent an anchor.</P>

<P><A NAME="1005213"></A>Anchors cannot be nested within other A tags.
You can enclose most character and paragraph formatting within the A tag.</P>

<P><A NAME="Syntax"></A><A NAME="1116164"></A></P>

<H4>Syntax </H4>

<P><A NAME="1116170"></A><TT>&lt;A <BR>
NAME=&quot;</TT>AnchorName<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
for an anchor <BR>
&gt; <BR>
... <BR>
&lt;/A&gt;</P>

<P><A NAME="Used within"></A><A NAME="1145072"></A></P>

<H4>Used within </H4>

<P><A NAME="1145073"></A>ADDRESS, DD, DT, H1 through H6, LI, P, PRE</P>

<P><A NAME="Example"></A><A NAME="1145074"></A></P>

<H4>Example </H4>

<P><A NAME="1145076"></A>This example defines the heading text &quot;Welcome
to the Marine Mammal page&quot; as an anchor in a document:</P>

<P><A NAME="1145077"></A><TT>&lt;A NAME=&quot;mammal_intro&quot;&gt;&lt;H2&gt;Welcome
to the Marine Mammal page&lt;/H2&gt;&lt;/A&gt;</TT></P>

<P><A NAME="1145078"></A>If this anchor is in a file called <TT>intro.html</TT>,
you could define a jump to the anchor as follows:</P>

<P><A NAME="1145079"></A><TT>&lt;A HREF=&quot;intro.html#mammal_intro&quot;&gt;Introduction
to marine mammals&lt;/A&gt;</TT></P>

<P><A NAME="A as link"></A><A NAME="1116172"></A></P>

<H3>A as link </H3>

<P><A NAME="1145058"></A>A link connects an HTML document to another document
(such as another HTML file or a graphic file) or part of a document (an
anchor in an HTML file). Navigator displays link text and ordinary text
differently, so users can easily distinguish hypertext jumps. By default,
Navigator displays links as blue underlined text or blue-bordered graphics
and visited links as magenta. The default color for links can be changed
in Navigator using the General Preferences command from the Options menu.
When the user clicks a link or image, the reference specified by the HREF
attribute is loaded into the window or frame specified by the TARGET attribute.</P>

<P><A NAME="1005215"></A>The destination of the link is usually another
document or a section of a document. The destination can also be a protocol
that specifies items such as an email message or an FTP site. To jump to
a specific section of a document, the HREF attribute should reference the
NAME attribute of an existing anchor.</P>

<P><A NAME="Syntax"></A><A NAME="1005217"></A></P>

<H4>Syntax </H4>

<P><A NAME="1067057"></A><TT>&lt;A <BR>
HREF=&quot;</TT>Location<TT>&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
for a link <BR>
<TT>NAME=&quot;</TT>AnchorName<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>optional
(and uncommon) in a link <BR>
<TT>ONCLICK=&quot;</TT>clickJScode<TT>&quot; <BR>
ONMOUSEOUT=&quot;</TT>outJScode<TT>&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<BR>
ONMOUSEOVER=&quot;</TT>overJScode<TT>&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<BR>
TARGET=&quot;</TT>WindowName<TT>&quot; <BR>
&gt; ... &lt;/A&gt;</TT></P>

<P><A NAME="1005220"></A>HREF=&quot;Location&quot; specifies a destination
URL for the anchor or link. </P>

<P><A NAME="1005221"></A>NAME=&quot;AnchorName&quot; specifies a name for
the anchor. A link to the anchor uses this value for its HREF attribute.</P>

<P><A NAME="1005222"></A>ONCLICK=&quot;clickJScode&quot; specifies JavaScript
code to execute when a user clicks the image or link text. See the JavaScript
Guide for information on event handlers.</P>

<P><A NAME="1096759"></A>ONMOUSEOUT=&quot;outJScode&quot; specifies JavaScript
code to execute when a user moves the mouse pointer out of the image or
link text. See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1028417"></A>ONMOUSEOVER=&quot;overJScode&quot; specifies JavaScript
code to execute when a user moves the mouse pointer over the image or link
text. See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1028422"></A>TARGET=&quot;WindowName&quot; is only used if
the anchor is also a link. It specifies the window that the link is loaded
into. <B><I>Navigator 2.0.</I></B> </P>

<H2>ADDRESS (format as address) </H2>

<P><A NAME="1005245"></A>The ADDRESS tag displays address information in
a format determined by each browser (Netscape Navigator displays addresses
in italic). An address can include authorship information and is usually
placed at the top or bottom of a document. </P>

<P><A NAME="Syntax"></A><A NAME="1005246"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005247"></A><TT>&lt;ADDRESS&gt;...&lt;/ADDRESS&gt;</TT></P>

<P><A NAME="Example"></A><A NAME="1005248"></A></P>

<H4>Example </H4>

italic.</P>

<P><A NAME="1033385"></A></P>

&lt;P&gt;

Netscape Communications Corporation&lt;BR&gt;

Navigator to load. Applet resources (including their classes) are normally

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1151641"></A><I>ALT=&quot;alternateText&quot; </I>specifies
text to display for browsers that do not support the APPLET tag. <B><I>Navigator
3.0</I></B> </P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1087181"></A><I>ARCHIVE=&quot;archiveURL&quot;</I> specifies
a file to be downloaded to the user's disk, and then searched for the <I>classFileName</I>
specified in the CODE attribute. The archiveURL is sought relative to the
classFileDirectory. The suffix on the archiveURL must be <I>.zip</I>, but
the file must not be compressed. Classes not found in the archiveURL are
searched for through the standard mechanism. <B><I>Navigator 3.0</I></B>
</P>

<P><A NAME="1081079"></A><I>CODE =&quot;classFileName&quot;</I> specifies
the filename of the applet you want to load. The file name must end with
a .class extension. </P>

<P><A NAME="1005260"></A><I>CODEBASE=&quot;</I>classFileDirectory<I>&quot;</I>
changes the URL specified by the BASE tag. If the CODEBASE attribute is
defined, it specifies a location to find applet resources. The value can
be an absolute URL or a relative URL. An absolute URL is used as is without
modification and is not affected by the document's BASE tag. When the CODEBASE
attribute is relative, then it is relative to the document-URL defined
by the BASE tag. If no base tag is specified, then it is relative to the
directory where the HTML file is.</P>

<P><A NAME="1033340"></A><I>HEIGHT=&quot;pixHeight&quot;</I> specifies
the height (in pixels) that the applet needs.</P>

<P><A NAME="1005264"></A><I>HSPACE=&quot;pixHoriz&quot; </I>specifies the
horizontal space (in pixels) that the applet needs between itself and surrounding
text.</P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1087200"></A><I>MAYSCRIPT</I> permits the applet to access
JavaScript. Use this attribute to determine whether or not an applet can
access JavaScript on a page without your knowlege. Accessing JavaScript
when the MAYSCRIPT attribute is not specified results in an exception.
<B><I>Navigator 3.0</I></B> </P>

<P><A NAME="1066152"></A><I>NAME =&quot;value&quot;</I> specifies the name
of the applet, so that different applets in the same window can refer to
(and communicate with) one another..</P>

<P><A NAME="1005265"></A><I>VSPACE=&quot;pixVert&quot;</I> specifies the
vertical space (in pixels) that the applet needs between itself and surrounding
text.</P>

<P><A NAME="1005266"></A><I>WIDTH=&quot;pixWidth&quot;</I> specifies the
width (in pixels) that the applet needs. The applet is scaled to fit the
specified height and width.</P>

<H2>AREA (client-side image maps) </H2>

<P><A NAME="1015319"></A>The AREA tag defines a client-side image map.
An image map is a graphic that has clickable regions that link to different
URLs. For example, you can have an image with a square and a circle where
a click in the square takes you to one page and a click in the circle takes
you to a different page.</P>

<P><A NAME="1015333"></A><B>Different areas of an image map can jump to
different Web pages. </B>_IMG SRC="tags1a3.gif" HEIGHT=99 WIDTH=324></P>

<P><A NAME="1005273"></A>Client-side image maps are defined by MAP and
AREA tags. When a user clicks the image, Navigator determines what URL
to load based, on the information in the AREA tag. The USEMAP attribute
of the IMG tag specifies an image as a client-side image map. The MAP tag
contains one or more AREA tags. Each AREA tag describes a different region
as a hyperlink in the image and specifies the URL to which it connects.</P>

<P><A NAME="Syntax"></A><A NAME="1005274"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005275"></A><TT>&lt;AREA <BR>
COORDS=&quot;</TT>x1<TT>,</TT>y1<TT>,</TT>x2<TT>,</TT>y2<TT>,...&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;|&quot;</TT>x-center<TT>,</TT>y-center<TT>,</TT>radius<TT>&quot;
<BR>
HREF=&quot;</TT>Location<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>NAME=&quot;</TT>areaName<TT>&quot; <BR>
NOHREF <BR>
ONMOUSEOUT=&quot;</TT>outJScode<TT>&quot; <BR>
ONMOUSEOVER=&quot;</TT>overJScode<TT>&quot; <BR>
SHAPE=&quot;CIRCLE&quot;|&quot;RECT&quot;|&quot;POLY&quot;|&quot;DEFAULT&quot;
<BR>
TARGET=&quot;</TT>WindowName<TT>&quot;&gt; </TT></P>

<P><A NAME="1015969"></A><I>COORDS </I>specifies the coordinates of the
region defined by the AREA tag. </P>

<P><A NAME="1017829"></A><I>HREF=&quot;Location&quot;</I> specifies the
URL of the document to load when a user clicks the area.</P>

<P><A NAME="1081121"></A><I>NAME=&quot;areaName&quot;</I> specifies the
map name to be used with the USEMAP attribute of the IMG tag. The value
of the <I>areaName</I> must begin with an alphanumeric character.</P>

<P><A NAME="1005283"></A><I>NOHREF</I> specifies that no URL is loaded
when a user clicks the area. </P>

<P><A NAME="1099544"></A>ONMOUSEOUT=&quot;outJScode&quot; specifies JavaScript
code to execute when a user moves the mouse pointer out of the image or
link text. See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1099549"></A>ONMOUSEOVER=&quot;overJScode&quot; specifies JavaScript
code to execute when a user moves the mouse pointer over the image or link
text. See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1073880"></A><B>Defining regions in an image </B>_IMG SRC="tags1a4.gif" HEIGHT=166 WIDTH=461></P>

<P><A NAME="1017525"></A><I>SHAPE </I>specifies the shape of the map. Each
shape has its own form of the COORDS attribute:</P>

<UL>
<P><A NAME="1017529"></A></P>

<LI>circle URL x,y,x,y specifies a circle. Circles need two coordinates--the
first pair identifies the circle center and the second identifies any point
on the circle's edge. <A NAME="1017531"></A></LI>

<LI>rect URL x,y,x,y specifies a rectangle by its upper left (first pair)
and lower right corners. <A NAME="1017533"></A></LI>

<LI>poly URL x,y,x,y specifies a polygon of up to 100 sides. Each x,y pair
is the point where two sides of the polygon meet. The last x,y pair is
connected to the first to enclose the polygon. <A NAME="1074059"></A></LI>

<LI>default URL defines the URL to jump to when someone clicks in an area
not specified by any regions. If you use a point in the map file, then
the default is never used. </LI>
</UL>

<P><A NAME="1073970"></A>If no SHAPE is defined, RECT is used. </P>

<BLOCKQUOTE><B><I></I></B></BLOCKQUOTE>

<P><A NAME="1068006"></A><I>TARGET=&quot;WindowName&quot;</I> specifies
the frame or window that the linked URL is loaded into. When a user clicks
an area that has a TARGET attribute, the URL is loaded in the specified
window or frame instead of in that containing the area. <B><I>Navigator2.0.
</I></B></P>

<H2>BASE (set base URL) </H2>

<P><A NAME="1069763"></A>The BASE tag specifies the base URL for the document
(from which all relative links in the document are to be resolved) or the
base target for the document (identifying the default window in which a
followed link displays). </P>

<P><A NAME="1069833"></A>When building complex, multi-page documents, you
might want to specify a base URL for the main document (master HTML file).
To do this, establish a base URL, then give relative URL addresses for
all referenced documents. </P>

<P><A NAME="1069801"></A>If the document is moved, and the base URL is
specified using the BASE tag, all relative references to URLs are updated
relative to the new location of the base URL.</P>

<P><A NAME="1069842"></A>If you have a document that contains links, and
you move it to a different URL, but do not specify a base URL, then when
Netscape Navigator resolves any relative URLs within the document it will
resolve them with respect to the new location, thus probably invalidating
them.. If you do specify a base URL, the relative URLS are resolved with
respect to that base. </P>

<P><A NAME="1005326"></A>The BASE tag does not require a closing tag. </P>

<P><A NAME="Syntax"></A><A NAME="1027912"></A></P>

<H4>Syntax </H4>

<P><A NAME="1027913"></A><TT>&lt;BASE <BR>
HREF=&quot;</TT>baseURL<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required<TT>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<BR>
TARGET=&quot;</TT>WindowName<TT>&quot; <BR>
&gt;</TT></P>

<P><A NAME="1027914"></A><I>HREF=&quot;baseURL&quot;</I> specifies the
location of the document as an absolute or relative URL. The absolute URL
is used as is without modification. If a relative URL is specified, all
subsequent links are relative to this URL.</P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1005330"></A><I>TARGET=&quot;WindowName&quot; </I>identifies
the default window or frame where any links activated from the current
document will display. <B><I>Navigator 2.0.</I></B> </P>

<H2>BR (line break) </H2>

<P><A NAME="1005388"></A>The BR tag breaks the line in the text flow of
your document. This lets you control where the next line of text appears,
which is especially useful when including graphics in a document. Unlike
the P tag, the BR tag does not add extra space.</P>

<P><A NAME="1005389"></A>The BR tag does not require a closing tag. </P>

<P><A NAME="Syntax"></A><A NAME="1005390"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005391"></A><TT>&lt;BR <BR>
CLEAR=&quot;</TT>ALL&quot;<TT>|&quot;LEFT&quot;|&quot;RIGHT&quot; <BR>
&gt; </TT></P>

<BLOCKQUOTE><B><I></I></B></BLOCKQUOTE>

<P><A NAME="1081191"></A><I>CLEAR </I>lets you flow text around an image
or figure. <B><I>Navigator 1.1</I></B></P>

<UL>
<UL>
<P><A NAME="1005393"></A></P>

<LI>ALL displays text at the next clear left and right margin. <A NAME="1005394"></A></LI>

<LI>LEFT displays text at the next clear left margin. <A NAME="1005395"></A></LI>

<LI>RIGHT displays text at the next clear right margin. </LI>
</UL>
</UL>

<P><A NAME="Example"></A><A NAME="1005397"></A></P>

<H4>Example </H4>

<P><A NAME="1005398"></A>The following example inserts line breaks in a
speech from <I>Hamlet.</I></P>

<P><A NAME="1019054"></A>Hamlet's famous speech begins:&lt;P&gt; <BR>
To be, or not to be&lt;BR&gt; <BR>
That is the question&lt;P&gt;</P>

<P><A NAME="1019140"></A>This puts space after the introductory clause,
but keeps the quote together. The last line uses the P tag to put more
space before the next line.</P>

<H2>CAPTION (display table caption) </H2>

<P><A NAME="1088229"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 1.1 </I></B></P>
</BLOCKQUOTE>

<P><A NAME="1005401"></A>The CAPTION tag defines a caption for a table.
Place the CAPTION tag within the TABLE tag but not inside the TD or the
TR tags.</P>

<P><A NAME="Syntax"></A><A NAME="1005402"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005403"></A><TT>&lt;CAPTION ALIGN=&quot;BOTTOM&quot;|&quot;TOP&quot;&gt;...&lt;/CAPTION&gt;</TT></P>

<P><A NAME="1005404"></A><I>ALIGN s</I>pecifies the placement of the caption
within a table. </P>

<UL>
<UL>
<P><A NAME="1005405"></A></P>

<LI>BOTTOM places the caption at the bottom of the table. <A NAME="1005406"></A></LI>

<LI>TOP places the caption at the top of the table. TOP is the default.
</LI>
</UL>
</UL>

<P><A NAME="Used within"></A><A NAME="1005407"></A></P>

<H4>Used within </H4>

&lt;TR&gt;&lt;TD&gt; two     &lt;/TD&gt;&lt;TD&gt; dos     &lt;/TD&gt;&lt;TD&gt; zwei   &lt;/TD&gt;&lt;/TR&gt;

&lt;TR&gt;&lt;TD&gt; three   &lt;/TD&gt;&lt;TD&gt; tres    &lt;/TD&gt;&lt;TD&gt; drei   &lt;/TD&gt;&lt;/TR&gt;

<H2>DL (definition list) </H2>

<P><A NAME="1005457"></A>The DL tag encloses a definition list. A definition
contains terms and definitions. Netscape Navigator displays the terms left
aligned and the definitions indented on the next line. </P>

<P><A NAME="Syntax"></A><A NAME="1005461"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005462"></A><TT>&lt;DL COMPACT&gt;...&lt;/DL&gt;</TT></P>

<P><A NAME="1075257"></A><I>COMPACT</I> &quot;compacts&quot; the definition
list by placing the term defined by the DT tag on the same line as the
definition defined by the DD tag, provided the term is short enough. </P>

<P><A NAME="Example"></A><A NAME="1024042"></A></P>

<H4>Example </H4>

<P><A NAME="1023402"></A>The following example defines three HTML terms.
</P>

<P><A NAME="1024047"></A></P>

<PRE><TT>All HTML files contain the following tags:&lt;P&gt;

&lt;DL COMPACT&gt;

&lt;DT&gt;HTML

&lt;DD&gt;This tag marks a text file as an HTML document.

&lt;DT&gt;HEAD

&lt;DD&gt;This tag defines the heading for the HTML document.

&lt;DT&gt;BODY

&lt;DD&gt;This tag defines the body for the HTML document.

&lt;DT&gt;DL

&lt;DD&gt;This tag defines a definition list in the HTML document.

&lt;DT&gt;DT

&lt;DD&gt;This tag defines a term in a definition list in the HTML document.

&lt;DT&gt;DT

&lt;DD&gt;This tag defines a definition in a definition list in the HTML
document.

&lt;/DL&gt;</TT>
</PRE>

<H2>FRAME (create an independent window region) </H2>

<P><A NAME="1005566"></A>The FRAME tag creates a frame, which is an individual,
independently scrolling region of a web page. The FRAMESET tag defines
a group of frames that display in one Netscape Navigator window. The FRAME
tag defines each individual frame in the Netscape Navigator window. Each
frame can be defined with unique features and characteristics using the
FRAME tag's attributes.</P>

<P><A NAME="1005567"></A>The content that each frame displays is determined
by a distinct URL. Links in a frame can cause a related frame to point
to a different URL, and frames can be targeted by other URLs within the
same window.</P>

<P><A NAME="Syntax"></A><A NAME="1005568"></A></P>

MARGINWIDTH=&quot;</TT>pixMarWidth<TT>&quot; <BR>
NAME=&quot;</TT>frameName<TT>&quot; <BR>
NORESIZE <BR>
SCROLLING=&quot;YES&quot;|&quot;NO&quot;|&quot;AUTO&quot; <BR>
SRC=&quot;</TT>URL<TT>&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>&gt;</TT></P>

<BLOCKQUOTE><B><I></I></B></BLOCKQUOTE>

<P><A NAME="1005570"></A><I>BORDERCOLOR=&quot;color&quot;</I> specifies
the color of the frame's borders. The color value <I>is a hexadecimal red-green-blue
triplet, or a color name. </I>See <A HREF="colors.htm#1002170">Appendix&nbsp;B,
&quot;Color values.&quot;</A><B><I>Navigator 3.0 </I></B></P>

<P><A NAME="1085146"></A>Because frame borders are shared, Navigator must
resolve any border color conflicts.</P>

<OL>
<OL>
<P><A NAME="1084391"></A></P>

<LI>Any attribute appearing in the outermost FRAMESET has the lowest priority.
<A NAME="1084398"></A></LI>

<LI>This attribute is, in turn, overridden by any attribute used in a nested

<LI>Finally, any BORDERCOLOR attribute in the current FRAME tag overrides

</UL>

<P><A NAME="1013308"></A><I>MARGINWIDTH=&quot;pixMarWidth&quot;</I> specifies
a margin in pixels between the left and right edges of the frame and the

<P><A NAME="1005609"></A>The following example creates a set of two frames.
The frameset is kept in a separate document file, such as index.html<TT>,</TT>
that contains no other information. When users navigate to the file, index.html
is loaded, and the FRAMESET tag within <TT>index.html</TT> then loads the
individual URLS referenced in the FRAME tag.</P>

<P><A NAME="1005610"></A></P>

<PRE><TT>&lt;FRAMESET COLS=&quot;30%,70%&quot;&gt;

&lt;/FRAMESET&gt;</TT>
</PRE>

<P><A NAME="1005611"></A>The two frames appear as columns because COLS
is specified within the FRAMESET tag. The left frame uses 30% of the available
space, and the right frame uses the remaining 70% of the space. By default,
the frames in this example have scroll bars and are resizable, because
no values are specified for the SCROLLING and NORESIZE attributes.</P>

<P><A NAME="1005623"></A>The code in this example creates a set of frames
similar to the following: _IMG SRC="tags2a.gif" HEIGHT=213 WIDTH=614></P>

<P><A NAME="1005624"></A>The frameset described in this example acts as
a table of contents. The table of contents entries in the left frame are
always available to the user. When users click a link in the left frame,
the right frame navigates to the chosen topic. Each link in the left frame
(the toc.html document file) uses &quot;contentFrame&quot; as the value
of its TARGET attribute, which forces the right frame to display the target
text.</P>

<H2>H1 through H6 (standard headings) </H2>

<P><A NAME="1028071"></A>HTML has six levels of headings, numbered 1 through
6, with 1 being the most prominent. Headings are displayed in different
fonts (larger and bold) than normal body text. </P>

<P><A NAME="Syntax"></A><A NAME="1005665"></A></P>

<P><A NAME="1005666"></A><TT>&lt;H1 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H1&gt;
<BR>
&lt;H2 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H2&gt;
<BR>
&lt;H3 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H3&gt;
<BR>
&lt;H4 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H4&gt;
<BR>
&lt;H5 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H5&gt;
<BR>
&lt;H6 ALIGN=&quot;</TT>LEFT&quot;|&quot;CENTER&quot;|&quot;RIGHT<TT>&quot;&gt;...&lt;/H6&gt;</TT></P>

<P><A NAME="1054737"></A><I>ALIGN </I>specifies the horizontal alignment
of the heading. The value can be: </P>

<UL>

<H2>HEAD (define document header) </H2>

<P><A NAME="1097555"></A>The HEAD tag defines the HTML document header.
The header contains information about the document, and can be used to
define JavaScript functions to be used in the document. None of the information
in the HEAD tag is displayed by the Web browser, except for text contained
by the TITLE tag. You should be careful not to put any of your document
content (other than JavaScript) in the HEAD tag. </P>

<P><A NAME="1097557"></A><TT>&lt;HEAD&gt;...&lt;/HEAD&gt;</TT></P>

&lt;ISINDEX&gt;, &lt;META&gt;, &lt;SCRIPT&gt;, and &lt;TITLE&gt;.</P>

<H2>HR (horizontal rule) </H2>

<P><A NAME="1005676"></A>The HR tag draws a horizontal line across the
document frame or window. You can use a horizontal line to visually divide
information or sections. The HR tag doesn't require a closing tag. </P>

<P><A NAME="Syntax"></A><A NAME="1005677"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005678"></A><TT>&lt;HR <BR>
ALIGN=&quot;</TT>CENTER&quot;|&quot;LEFT&quot;|&quot;RIGHT&quot;<TT> <BR>
NOSHADE <BR>
SIZE=&quot;</TT>pixThick<TT>&quot; <BR>
WIDTH=&quot;</TT>value<TT>&quot; <BR>
&gt;</TT></P>

<P><A NAME="1083442"></A><I>ALIGN</I> specifies the horizontal alignment
of lines that do not span the width of the page. <B><I>Navigator 1.1</I></B>
</P>

<UL>
<UL>
<P><A NAME="1005680"></A></P>

<LI>CENTER displays the line centered (the default). <A NAME="1005681"></A></LI>

<LI>LEFT aligns the line flush left. <A NAME="1005682"></A></LI>

<LI>RIGHT aligns the line flush right. </LI>
</UL>
</UL>

<P><A NAME="1005683"></A><I>NOSHADE</I> removes any line shading, producing
a solid black line. <B><I>Navigator 1.1</I></B> </P>

<P><A NAME="1005684"></A><I>SIZE=&quot;pixThick&quot;</I> indicates the
thickness of the line in pixels. The default is 2 pixels. <B><I>Navigator
1.1</I></B> </P>

<P><A NAME="1005685"></A><I>WIDTH=&quot;pixPct&quot;</I> defines the horizontal
width of the line. The default is the width of the page. The measurement
value can be a number of pixels or a percentage of the page width or frame
width. <B><I>Navigator 1.1</I></B></P>

<P><A NAME="Example"></A><A NAME="1005686"></A></P>

<H4>Example </H4>

<P><A NAME="1005687"></A>The following example draws a horizontal rule
between two sentences.</P>

<P><A NAME="1005688"></A></P>

<PRE><TT>This text appears above a thick, unshaded, centered horizontal rule.

&lt;HR NOSHADE ALIGN=&quot;CENTER&quot; WIDTH=&quot;50%&quot; SIZE=&quot;8&quot;&gt;

<H2>INPUT (create input elements in a form) </H2>

<P><A NAME="1125260"></A>The INPUT tag lets you create input fields inside
a form. An input field lets the user enter information on an HTML form.
The TYPE attribute determines the specific sort of form element to be created:</P>

<UL>
<P><A NAME="1125313"></A></P>

<LI>BUTTON places a button on an HTML form. Use JavaScript code to make
the button perform an action you define. <A HREF="#1136715">See&nbsp;&quot;INPUT
TYPE=&quot;BUTTON&quot;&quot; on page 106</A>. <A NAME="1125262"></A></LI>

<LI>CHECKBOX places a toggle switch on an HTML form, letting the user set
a value on or off. <A HREF="#1138315">See&nbsp;&quot;INPUT TYPE=&quot;CHECKBOX&quot;&quot;
on page 107</A>. </LI>
</UL>

<UL>
<P><A NAME="1144991"></A></P>

<LI>FILE places an element on an HTML form letting the user supply a file
as input. When the form is submitted, the content of the specified file
is sent to the server along with the other form data. <A HREF="#1139772">See&nbsp;&quot;INPUT
TYPE=&quot;FILE&quot;&quot; on page 108</A>. <B><I>Navigator 2.0.</I></B>
<A NAME="1135140"></A></LI>

<LI>HIDDEN places a text element that is suppressed from form display on
an HTML form. A hidden element is used for passing information to the server
when a form is submitted. <A HREF="#1141311">See&nbsp;&quot;INPUT
TYPE=&quot;HIDDEN&quot;&quot; on page 109</A>. <A NAME="1145011"></A></LI>

<LI>IMAGE places an image, serving as a custom button, on an HTML form.
When a user clicks an image element, the form is submitted to the server.
<A HREF="#1141701">See&nbsp;&quot;INPUT TYPE=&quot;IMAGE&quot;&quot;
on page 110</A>. <A NAME="1145031"></A></LI>

<LI>PASSWORD places a text input field on an HTML form that conceals its
value. When the user enters text into the field, a character such as *
or a black dot hides anything entered from view. <A HREF="#1144719">See&nbsp;&quot;INPUT
TYPE=&quot;PASSWORD&quot;&quot; on page 111</A>. <A NAME="1145051"></A></LI>

<LI>RADIO places a radio button on an HTML form. A set of radio buttons
that all have the same NAME attribute lets the user choose one item from
the set. If one radio button in a set has the CHECKED attriubute, that
one is selected when the set is first laid out on the window. <A HREF="#1126528">See&nbsp;&quot;INPUT
TYPE=&quot;RADIO&quot;&quot; on page 112</A>. <A NAME="1135175"></A></LI>

<LI>RESET places a reset button on an HTML form. When a user presses a
reset button, all elements in the form are reset to their default values.
<A HREF="#1126837">See&nbsp;&quot;INPUT TYPE=&quot;RESET&quot;&quot;
on page 113</A>. <A NAME="1135215"></A></LI>

<LI>SUBMIT places a submit button on an HTML form. When a user presses
a submit button, the form is submitted to the server. <A HREF="#1126830">See&nbsp;&quot;INPUT
TYPE=&quot;SUBMIT&quot;&quot; on page 114</A>. <A NAME="1144983"></A></LI>

<LI>TEXT places a text input field on an HTML form. A text field lets the
user enter a word, phrase, or series of numbers. <A HREF="#1143270">See&nbsp;&quot;INPUT

<H2>ISINDEX (indicate presence of searchable index) </H2>

<P><A NAME="1005839"></A>The ISINDEX tag indicates that the document has
a searchable index. An HTML index document can be read and queried using
a keyword search, if the server has access to a search engine. Generally,
documents with the ISINDEX tag include a user interface element (such as
a button) or a prompt to initiate the search. You can control the text
that appears as part of the search by using the PROMPT attribute. </P>

<P><A NAME="1005840"></A>The keywords are passed to the server by adding
a question mark to the end of the URL followed by a list of keywords separated
by a plus sign. For example:</P>

<P><A NAME="1005841"></A></P>

<PRE><TT>http://www.acme.com/products/index.htm?inventory+ordering+shipping </TT>
</PRE>

<P><A NAME="1005842"></A>Note that ISINDEX does not require a closing tag.
</P>

<P><A NAME="Syntax"></A><A NAME="1054738"></A></P>

<H4>Syntax </H4>

<P><A NAME="1054739"></A><TT>&lt;ISINDEX PROMPT=&quot;</TT>text<TT>&quot;
&gt;</TT></P>

<P><A NAME="1054741"></A><I>PROMPT=&quot;text&quot;</I> specifies the text
that appears as the search prompt in the browser. <B><I>Navigator 1.1</I></B>
</P>

<H2>KEYGEN (generate key material) </H2>

<P><A NAME="1076160"></A>The KEYGEN tag facilitates the generation of key
material and submission of the public key as part of an HTML form. This
mechanism is designed for use in web-based certificate management systems.
It displays a menu of key-size choices from which the user must choose
one. Then, when the submit button is pressed, a key pair of the selected
size is generated. The private key is encrypted and stored in the local
key database. </P>

<P><A NAME="1076450"></A>The public key and challenge string are DER encoded
as PublicKeyAndChallenge, and then digitally signed with the private key
to produce a SignedPublicKeyAndChallenge. The SignedPublicKeyAndChallenge
is base64 encoded, and the ASCII data is finally submitted to the server
as the value of a name-value pair, where the name is name as specified
by the NAME attribute of the KEYGEN tag. </P>

<P><A NAME="Syntax"></A><A NAME="1076186"></A></P>

<H4>Syntax </H4>

<P><A NAME="1076982"></A><TT>&lt;KEYGEN <BR>
NAME=&quot;</TT>name<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>CHALLENGE=&quot;</TT>challenge<TT>&quot; <BR>
&gt;</TT></P>

<P><A NAME="1076984"></A><I>NAME=&quot;name&quot; </I>specifies the name
for the name-value pair.</P>

<P><A NAME="1098127"></A><I>CHALLENGE=&quot;challenge&quot; </I>specifies
the challenge string to be packaged with the public key in the PublicKeyAndChallengefor
use in verification of the form submission. If no challenge string is provided,
then it is encoded as an IA5STRING of length zero.</P>

<H2>MAP (define client-side image map) </H2>

<P><A NAME="1005880"></A>An image map is a graphic that contains hyperlinks.
The image map can be divided into many regions, and each region of the
map can point to a different URL. When a user clicks a specific region
of the image map, Navigator loads a specific URL.</P>

<P><A NAME="1005881"></A>Client-side image maps are defined by the MAP
and AREA tags and loaded into the Navigator as hypergraphics. When a user
clicks the image, Navigator determines what URL to load based on the information
in the AREA tag. The USEMAP attribute of the IMG tag specifies an image
as a client-side image map.</P>

<P><A NAME="Syntax"></A><A NAME="1005882"></A></P>

<H4>Syntax </H4>

<P><A NAME="1005883"></A><TT>&lt;MAP <BR>
NAME=&quot;</TT>mapName<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>&gt; <BR>
... <BR>
&lt;/MAP&gt;</TT></P>

<P><A NAME="1005884"></A><I>NAME=&quot;mapName&quot;</I> specifies the
name of the map.</P>

<P><A NAME="Example"></A><A NAME="1005885"></A></P>

<H4>Example </H4>

<HR><A NAME="META (meta-document information)"></A><A NAME="1005921"></A></P>

<H2>META (meta-document information) </H2>

<P><A NAME="1005922"></A>The META tag specifies meta-document information
or creates an HTTP response header. The META tag provides a way to store
information about the document that is not available elsewhere in the document.
For example, the META tag can contain catalog, author, or index information
that various search engines can use.</P>

<P><A NAME="1005923"></A>The META tag creates a special HTTP response header
that the server sends to the client before transmitting the HTML document.
This form of the META syntax is frequently used to implement client pull.</P>

<P><A NAME="1005924"></A>When you create an HTTP header with META, do not
override a response header field that is normally returned by the server.
Use META to create a special response header field, such as a &quot;refresh&quot;
field that implements client pull.</P>

<P><A NAME="Syntax"></A><A NAME="1005925"></A></P>

<H4>Syntax </H4>

<P><A NAME="1067591"></A><TT>&lt;META <BR>
CONTENT=&quot;</TT>value<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>HTTP-EQUIV=&quot;</TT>FieldName<TT>&quot; <BR>
NAME=&quot;name&quot; <BR>
&gt;</TT></P>

<P><A NAME="1087821"></A><I>CONTENT=&quot;FieldContent&quot;</I> specifies
the value of the HTTP response header field created by HTTP-EQUIV.<B><I>Navigator
1.1</I></B> </P>

<P><A NAME="1067599"></A><I>HTTP-EQUIV=&quot;FieldName&quot;</I> specifies
the name of the HTTP response header field.</P>

<P><A NAME="1159429"></A>NAME=&quot;name&quot; specifies a name for the
meta-document information. Different programs that access meta-document
information expect different values for this attribute</P>

<P><A NAME="Used within"></A><A NAME="1005933"></A></P>

<H4>Used within </H4>

<P><A NAME="1005934"></A>HEAD</P>

<P><A NAME="Examples"></A><A NAME="1005935"></A></P>

<H4>Examples </H4>

<P><A NAME="1005936"></A><B>Example 1: indexing information</B></P>

<P><A NAME="1005937"></A>In this example, the META tag stores indexing
information that a search engine uses when it accesses the document. This
search engine expects the NAME attribute to have a value of &quot;keywords&quot;
when a document is indexed. Search utilities and some webcrawlers used
by web search servers will catalog this information. The index keywords
are stored as the value of the CONTENT attribute.</P>

<P><A NAME="1005938"></A></P>

<PRE><TT>&lt;HEAD&gt;

&lt;TITLE&gt;HTML Reference&lt;/TITLE&gt;

&lt;META NAME=&quot;keywords&quot;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;CONTENT=&quot;HTML documentation reference Netscape&quot;&gt;

&lt;/HEAD&gt;</TT>
</PRE>

&quot;documentation&quot;, &quot;reference&quot;, and &quot;Netscape&quot;.</P>

<P><A NAME="1005941"></A>In this example, the META tag creates a special

by the server when an HTTP connection for this document is established.</P>

<PRE><TT>&lt;HEAD&gt;

&lt;/HEAD&gt;</TT>
</PRE>

<P><A NAME="1076158"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 3.0</I></B> </P>
</BLOCKQUOTE>

<P><A NAME="1102819"></A>The MULTICOL tag establishes an area of the document
as having multiple, equal-width columns. </P>

<P><A NAME="Syntax"></A><A NAME="1077166"></A></P>

<H4>Syntax </H4>

<P><A NAME="1077189"></A><TT>&lt;MULTICOL <BR>
COLS=&quot;number&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>GUTTER=&quot;gwidth&quot; <BR>
WIDTH=&quot;colwidth&quot; <BR>
&gt; <BR>
... <BR>
&lt;/MULTICOL&gt;</TT></P>

<P><A NAME="1077190"></A><I>COLS=&quot;number&quot;</I> specifies the number
of text columns for the text display. Netscape Navigator attempts to flow
elements evenly across the columns to make each column be about the same
height. Unless the WIDTH attribute is present, column width is adjusted
to fill the available view. </P>

<P><A NAME="1077778"></A><I>GUTTER=&quot;gwidth&quot;</I> specifies the
number of pixels to appear between columns. If it is not specified, Netscape
Navigator uses 10. </P>

<P><A NAME="1077956"></A><I>WIDTH=&quot;colwidth&quot;</I> specifies the
width of each column in the group, in pixels. All columns are the same
width. If WIDTH is not present, its value is determined by subtracting
from the display width the number of pixels that constitute the gutter
and then dividing by the number of columns </P>

<H2>P (paragraph) </H2>

<P><A NAME="1006012"></A>The P tag specifies a paragraph. You must use
the P tag to separate content because in HTML carriage returns aren't significant.
The P tag puts space after the paragraph (unlike the BR tag). Most browsers
do not recognize the ending tag.</P>

<P><A NAME="Syntax"></A><A NAME="1006013"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006014"></A><TT>&lt;P <BR>

&gt; <BR>
... <BR>
&lt;/P&gt;</TT></P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1006015"></A><I>ALIGN </I>specifies the horizontal alignment
of the paragraph. <B><I>Navigator 1.1</I></B> The <I>value</I> can be:
</P>

<UL>
<UL>
<P><A NAME="1006016"></A></P>

<LI>LEFT aligns the paragraph flush left (the default). <A NAME="1006017"></A></LI>

<LI>CENTER centers the paragraph. <A NAME="1006018"></A></LI>

<LI>RIGHT aligns the paragraph flush right. </LI>
</UL>
</UL>

a new paragraph. <BR>
&lt;P&gt; The &amp;lt;/P&amp;gt; tag can terminate a paragraph, but few

<H2>PRE (preformatted text, fixed-width font, no join) </H2>

<P><A NAME="1075976"></A>The PRE tag displays preformatted text in the
fixed-width font as determined by the font setting (Options|General Preferences).
Using this tag you can insert and reproduce formatted text, preserving
its original layout, but you have to use entities for the &lt;&gt; and
other symbols. The &lt;PRE&gt; tag suspends text joining and blank suppression.
This makes the &lt;PRE&gt; tag useful for duplicating blocks of text that
were created for some text-only form, such as electronic mail messages
and news postings. </P>

<P><A NAME="1006045"></A>The PRE tag does not suppress interpretation of
other HTML tags, unlike XMP and PLAINTEXT. </P>

<P><A NAME="1006063"></A>The SCRIPT tag specifies client-side JavaScript

<TT>SRC=&quot;</TT>Location<TT>&quot;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;

<P><B><I>Navigator 3.0 </I></B></P>
</BLOCKQUOTE>

<P><A NAME="1083900"></A>The SPACER tag provides better control over the
spacing of objects and whitespace in HTML pages. It governs the space between
words or between lines, or creates a spacing rectangle, similar to an invisible
image. </P>

<P><A NAME="Syntax"></A><A NAME="1083886"></A></P>

<H4>Syntax </H4>

<P><A NAME="1083887"></A><TT>&lt;SPACER <BR>
ALIGN=&quot;LEFT&quot;|&quot;RIGHT&quot;|&quot;TOP&quot;|&quot;ABSMIDDLE&quot;|&quot;ABSBOTTOM&quot;|
<BR>
&quot;TEXTTOP&quot;|&quot;MIDDLE&quot;|&quot;BASELINE&quot;|&quot;BOTTOM&quot;
<BR>
HEIGHT=&quot;value&quot; <BR>
SIZE=&quot;value&quot; <BR>
TYPE=&quot;HORIZONTAL&quot;|&quot;VERTICAL&quot;|&quot;BLOCK&quot; <BR>
WIDTH=&quot;value&quot; <BR>
&gt;</TT></P>

<P><A NAME="1148302"></A><I>ALIGN </I>applies only when the spacer is of
type BLOCK, and specifies the alignment of the spacing rectangle in relation
to the surrounding text. If you do not specify a value for ALIGN, Navigator
uses &quot;BOTTOM&quot; as the default.</P>

<UL>
<UL>
<P><A NAME="1148303"></A></P>

<LI>LEFT aligns a spacing rectangle with the left margin. <A NAME="1084014"></A></LI>

<LI>RIGHT aligns a spacing rectangle with the right margin. <A NAME="1084015"></A></LI>

<LI>TOP aligns the top of a spacing rectangle with the top of the tallest
item in the current line. <A NAME="1084016"></A></LI>

<LI>ABSMIDDLE aligns the middle of a spacing rectangle with the middle
of the text in the current line. <A NAME="1084017"></A></LI>

<LI>ABSBOTTOM aligns the bottom of a spacing rectangle with the bottom
of the lowest item in the current line. <A NAME="1084018"></A></LI>

<LI>TEXTTOP aligns the top of a spacing rectangle with the top of the tallest
text in the current line. <A NAME="1084019"></A></LI>

<LI>MIDDLE aligns the middle of a spacing rectangle with the baseline of
the text in the current line. <A NAME="1084020"></A></LI>

<LI>BASELINE aligns the bottom of a spacing rectangle with the baseline
of the text in the current line. <A NAME="1084140"></A></LI>

<LI>BOTTOM is the same as BASELINE. </LI>
</UL>
</UL>

<P><A NAME="1084142"></A><I>HEIGHT=&quot;value&quot;</I> applies only when
the spacer is of type BLOCK, and specifies the height of the spacing rectangle
in pixels. </P>

<P><A NAME="1083999"></A><I>SIZE=&quot;pixelSize&quot;</I> depents on the
value of TYPE. When the spacer is of type BLOCK, <I>pixelSize</I> specifies
the absolute width or height in pixels of the spacing rectangle. When the
spacer is of type HORIZONTAL or VERTICAL <I>pixelSize</I> specifies the
absolute width or height in pixels of the added space. </P>

<P><A NAME="1083873"></A><I>TYPE </I>specifies whether the spacing is that
between words, that between lines, or that of a rectangular space. </P>

<UL>
<P><A NAME="1084259"></A></P>

<LI>HORIZONTAL inserts horizontal space between words. The width of this
space is specified by the SIZE attribute. <A NAME="1084264"></A></LI>

<LI>VERTICAL inserts vertical space between lines. Implicit in this spacer
is a line break to end the current line, then Navigator adds the vertical
space before the beginning of the next line. The height of the space is
specified by the SIZE attribute. <A NAME="1084265"></A></LI>

<LI>BLOCK behaves almost exactly like an invisible image. The Navigator
ignores any SIZE attribute and instead uses the HEIGHT, WIDTH, and ALIGN
attributes to define a spacing rectangle. </LI>
</UL>

<P><A NAME="1084224"></A><I>WIDTH=&quot;value&quot;</I> applies only when
the spacer is of type BLOCK, and specifies the width of the spacing rectangle
in pixels.</P>

<H2>TABLE (define a table) </H2>

<P><A NAME="1006183"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 1.1</I></B> </P>
</BLOCKQUOTE>

<P><A NAME="1087856"></A>The TABLE tag defines a table. Rows are defined
by the &lt;TR&gt; tag and cells within the rows by the &lt;TD&gt; tag.
</P>

<P><A NAME="Syntax"></A><A NAME="1006184"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006185"></A><TT>&lt;TABLE <BR>
ALIGN=&quot;</TT>LEFT&quot;|&quot;RIGHT<TT>&quot; <BR>
BGCOLOR=&quot;</TT>color<TT>&quot; <BR>
BORDER=&quot;</TT>value<TT>&quot; <BR>
CELLPADDING=&quot;</TT>value<TT>&quot; <BR>
CELLSPACING=&quot;</TT>value<TT>&quot; <BR>
HEIGHT=&quot;</TT>height<TT>&quot; <BR>
HSPACE=&quot;</TT>pixHoriz<TT>&quot; <BR>
WIDTH=&quot;</TT>pixels<TT>&quot;|&quot;</TT>value%<TT>&quot; <BR>
VSPACE=&quot;</TT>pixVert<TT>&quot; <BR>
&gt; <BR>
... <BR>
&lt;/TABLE&gt;</TT></P>

<P><A NAME="1006186"></A><I>ALIGN </I>specifies the horizontal placement
of the table: </P>

<UL>
<UL>
<P><A NAME="1006189"></A></P>

<LI>LEFT aligns the table with the text's left margin (the default). <A NAME="1006190"></A></LI>

<LI>RIGHT aligns the table with the text's right margin. </LI>
</UL>
</UL>

<P><A NAME="1117415"></A>If you want to center a table, you can use the
DIV tag with ALIGN=&quot;CENTER&quot; around the table.</P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1085009"></A><I>BGCOLOR=&quot;color&quot; changes </I>the color
of the background for the table. This color can be overridden by a BGCOLOR
tag in the TH, TR, or TD tags. The value of color <I>is a hexadecimal red-green-blue
triplet, or a color name. </I>See <A HREF="colors.htm#1002170">Appendix&nbsp;B,
&quot;Color values.&quot;</A><B><I>Navigator 3.0</I></B> </P>

<P><A NAME="1006192"></A><I>BORDER=&quot;value&quot;</I> draws a border
around the table. The value is the number of borders (lines) you want around
the table. Use a value of 0 to use the space reserved for borders to expand
the area of your table. </P>

<P><A NAME="1006193"></A><I>CELLPADDING=&quot;value&quot;</I> determines
the amount of space between the border of a cell and the contents of the
cell. The default is 1. </P>

<P><A NAME="1006194"></A><I>CELLSPACING=&quot;value&quot;</I> determines
the amount of space between individual cells in a table. The default is
2. </P>

<P><A NAME="1006195"></A><I>HEIGHT=&quot;height&quot;</I> specifies the
height in pixels that the table must fit. The table is scaled to fit the
specified height and width.</P>

<P><A NAME="1006196"></A><I>HSPACE=&quot;pixHoriz&quot;</I> specifies the
horizontal space in pixels within which the table must fit. The table is
scaled to fit the specified height and width</P>

<P><A NAME="1159672"></A><I>VSPACE=&quot;pixVert&quot;</I> specifies the
vertical space in pixels within which the table must fit. The table is
scaled to fit the specified height and width.</P>

<P><A NAME="1006197"></A><I>WIDTH=&quot;pixels&quot;|&quot;value%&quot;</I>
defines the width of the table. The default is the optimal width determined
by the contents of each cell. The measurement value can be a number of
pixels or the width as a percentage of the page size. </P>

<P><A NAME="Example"></A><A NAME="1159576"></A></P>

<H4>Example </H4>

<P><A NAME="1006200"></A>The following example creates a three-column,
four-row table, with the caption &quot;Tables are as easy as one, two,
three&quot; aligned at the bottom of the table.</P>

<P><A NAME="1006201"></A></P>

<PRE><TT>&lt;TABLE BORDER CELLPADDING=&quot;8&quot; CELLSPACING=&quot;4&quot;&gt;

&lt;TR&gt;&lt;TH&gt; English &lt;/TH&gt;&lt;TH&gt; Spanish &lt;/TH&gt;&lt;TH&gt; German &lt;/TH&gt;&lt;/TR&gt;

&lt;TR&gt;&lt;TD&gt; one     &lt;/TD&gt;&lt;TD&gt; uno     &lt;/TD&gt;&lt;TD&gt; ein    &lt;/TD&gt;&lt;/TR&gt;

&lt;TR&gt;&lt;TD&gt; two     &lt;/TD&gt;&lt;TD&gt; dos     &lt;/TD&gt;&lt;TD&gt; zwei   &lt;/TD&gt;&lt;/TR&gt;

&lt;TR&gt;&lt;TD&gt; three   &lt;/TD&gt;&lt;TD&gt; tres    &lt;/TD&gt;&lt;TD&gt; drei   &lt;/TD&gt;&lt;/TR&gt;

&lt;CAPTION ALIGN=&quot;BOTTOM&quot;&gt; &lt;B&gt;Table 1&lt;/B&gt;: Tables are as easy as one, two, three

&lt;/CAPTION&gt;

&lt;/TABLE&gt;</TT>
</PRE>

<P><A NAME="1048583"></A>_IMG SRC="tags3a13.gif" HEIGHT=237 WIDTH=377></P>

<H2>TD (table data) </H2>

<P><A NAME="1088199"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 1.1</I></B> </P>
</BLOCKQUOTE>

Place the TD tag within the TABLE tag.</P>

<P><A NAME="Syntax"></A><A NAME="1006206"></A></P>

<H4>Syntax </H4>

BGCOLOR=&quot;</TT>value<TT>&quot; <BR>
COLSPAN=&quot;</TT>value<TT>&quot; <BR>
NOWRAP=&quot;</TT>value<TT>&quot; <BR>
ROWSPAN=&quot;</TT>value<TT>&quot; <BR>
VALIGN=&quot;BASELINE&quot;|&quot;BOTTOM&quot;|&quot;MIDDLE&quot;|&quot;TOP&quot;
<BR>
&gt; <BR>
... <BR>

<LI>RIGHT aligns the table with the text's right margin. </LI>

<P><A NAME="1028568"></A><I>NOWRAP specifies</I> that the lines within

<P><A NAME="1028569"></A><I>ROWSPAN=&quot;value&quot; </I>indicates the
number of rows the cell spans. </P>

<P><A NAME="1006217"></A><I>VALIGN </I>specifies the vertical placement
of the text within a cell: </P>

<UL>
<UL>
<P><A NAME="1006218"></A></P>

<LI>BASELINE aligns the text with the cell's baseline. <A NAME="1006219"></A></LI>

<LI>BOTTOM aligns the text with the cell's bottom. <A NAME="1006220"></A></LI>

<LI>MIDDLE centers the text within the cell (the default). <A NAME="1006221"></A></LI>

<LI>TOP aligns the text with the cell's top. </LI>
</UL>
</UL>

<H2>TEXTAREA (text field on a form) </H2>

<P><A NAME="1006230"></A>The TEXTAREA tag defines a multiline input field
on an HTML form. A textarea field lets the user enter words, phrases, or
numbers.</P>

<P><A NAME="1006238"></A>The following figure shows a textarea element:
_IMG SRC="tags3a14.gif" HEIGHT=260 WIDTH=466></P>

<P><A NAME="1006239"></A>Scrollbars appear if the text in the textarea
element exceeds the number of columns or rows in the box.</P>

<P><A NAME="1006240"></A>To begin a new line in a textarea element, use
a new paragraph. For example, the following textarea element contains two
lines, a blank line, then one line:</P>

<P><A NAME="1006241"></A></P>

<PRE><TT>&lt;FORM&gt;

&lt;B&gt;Description:&lt;/B&gt;

&lt;BR&gt;&lt;TEXTAREA NAME=&quot;item_description&quot; ROWS=&quot;6&quot; COLS=&quot;55&quot;&gt;

This is the first line.

This is the second line.



This is the last line.

&lt;/TEXTAREA&gt;

&lt;/FORM&gt;</TT>
</PRE>

<P><A NAME="1048625"></A>_IMG SRC="tags3a15.gif" HEIGHT=199 WIDTH=379></P>

<P><A NAME="Syntax"></A><A NAME="1006242"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006243"></A><TT>&lt;TEXTAREA <BR>
COLS=&quot;</TT>value<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>NAME=&quot;</TT>textareaName<TT>&quot; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</TT>required
<BR>
<TT>ONBLUR=&quot;</TT>blurJScode<TT>&quot; <BR>
ONCHANGE=&quot;</TT>changeJScode<TT>&quot; <BR>
ONFOCUS=&quot;</TT>focusJScode<TT>&quot; <BR>
ONSELECT=&quot;</TT>selectJScode<TT>&quot; <BR>
ROWS=&quot;</TT>integer<TT>&quot; <BR>
WRAP=&quot;OFF&quot;|&quot;HARD&quot;|&quot;SOFT&quot; <BR>
&gt; <BR>
</TT>textToDisplay <BR>
<TT>&lt;/TEXTAREA&gt;</TT></P>

<P><A NAME="1006245"></A><I>COLS=&quot;value&quot;</I> defines the width
(number of characters per line) the textarea can accommodate without scrolling.</P>

<P><A NAME="1006246"></A><I>NAME=&quot;textareaName&quot;</I> specifies
the name of the textarea element. This value is the <I>name</I> portion
of the <I>name=value</I> pair sent to the server when the form is submitted.
The name is not displayed on the form.</P>

<P><A NAME="1006247"></A><I>ONBLUR=&quot;blurJScode&quot;</I> specifies
JavaScript code to execute when the textarea element loses focus. See the
JavaScript Guide for information on event handlers.</P>

<P><A NAME="1006251"></A><I>ONCHANGE=&quot;changeJScode&quot;</I> specifies
JavaScript code to execute when the textarea element loses focus and its
value has been modified. See the JavaScript for information on event handlers.</P>

<P><A NAME="1006255"></A><I>ONFOCUS=&quot;focusJScode</I> specifies JavaScript
code to execute when a user clicks the textarea element or tabs to it.
See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1006259"></A><I>ONSELECT=&quot;selectJScode&quot;</I> specifies
JavaScript code to execute when a user selects some of the text in the
textarea element. See the JavaScript Guide for information on event handlers.</P>

<P><A NAME="1006263"></A><I>ROWS=&quot;integer&quot; </I>defines the height
(number of rows) the textarea can accommodate without scrolling.</P>

<P><A NAME="1159713"></A><I>textToDisplay</I> specifies the label to display
in the textarea.</P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1006264"></A><I>WRAP </I>specifies whether lines longer than
the textarea's column width wrap to the next line. <B><I>Navigator 2.0.</I></B>
The <I>value</I> can be:</P>

<UL>
<UL>
<P><A NAME="1006265"></A></P>

<LI>OFF disables word wrap. Text the user types is displayed exactly as
typed. If the user explicitly inserts a line break, however, the break
is included as part of the textarea's value. <A NAME="1006266"></A></LI>

<LI>HARD causes word wrap, and the line breaks are included when the form
is submitted. <A NAME="1006267"></A></LI>

<LI>SOFT causes word wrap, but the line breaks are not included when the
form is submitted. </LI>
</UL>
</UL>

<H4>Used within </H4>

<P><A NAME="1006269"></A>FORM</P>

<P><A NAME="Example"></A><A NAME="1006270"></A></P>

<P><A NAME="1006272"></A></P>

<PRE><TT>&lt;FORM&gt;

&lt;/TEXTAREA&gt;

&lt;/FORM&gt;</TT>
</PRE>

<P><A NAME="1088207"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 1.1</I></B> </P>
</BLOCKQUOTE>

<P><A NAME="1006276"></A>The TH tag specifies a table heading.</P>

<P><A NAME="Syntax"></A><A NAME="1006277"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006278"></A><TT>&lt;TH <BR>
ALIGN=&quot;CENTER&quot;|&quot;LEFT&quot;|&quot;RIGHT&quot; <BR>
BGCOLOR=&quot;</TT>color<TT>&quot; <BR>
COLSPAN=&quot;</TT>value<TT>&quot; <BR>
NOWRAP <BR>
ROWSPAN=&quot;</TT>value<TT>&quot; <BR>
VALIGN=&quot;BASELINE&quot;|&quot;BOTTOM&quot;|&quot;MIDDLE&quot;|&quot;TOP&quot;
<BR>
&gt; <BR>
... <BR>
&lt;/TH&gt;</TT></P>

<P><A NAME="1006279"></A><I>ALIGN </I>specifies the horizontal placement
of the table: </P>

<UL>
<UL>
<P><A NAME="1006282"></A></P>

<LI>CENTER centers the table within the text's left and right margins.
<A NAME="1006284"></A></LI>

<LI>LEFT aligns the table with the text's left margin (the default). <A NAME="1006285"></A></LI>

<LI>RIGHT aligns the table with the text's right margin. </LI>
</UL>
</UL>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1006286"></A><I>BGCOLOR=&quot;color&quot; </I>changes the color
of the background of the table heading. This color can be overridden by
a BGCOLOR tag in the TD tags within the scope of the TH tag. The color
value <I>is a hexadecimal red-green-blue triplet, or a color name. </I>See
<A HREF="colors.htm#1002170">Appendix&nbsp;B, &quot;Color values.&quot;</A><B><I>Navigator
3.0</I></B> </P>

<P><A NAME="1006287"></A><I>COLSPAN=&quot;value&quot;</I> indicates the
number of columns the cell spans<I>. </I></P>

<P><A NAME="1006288"></A><I>NOWRAP specifies</I> that the lines within
a cell cannot be broken (in other words, are not word wrapped). </P>

<P><A NAME="1006289"></A><I>ROWSPAN </I>indicates the number of rows the
cell spans. </P>

<P><A NAME="1006290"></A><I>VALIGN </I>specifies the vertical placement
of the text within a cell: </P>

<UL>
<UL>
<P><A NAME="1006291"></A></P>

<LI>BASELINE aligns the text with the cell's baseline. <A NAME="1006292"></A></LI>

<LI>BOTTOM aligns the text with the cell's bottom. <A NAME="1006293"></A></LI>

<LI>MIDDLE centers the text within the cell (the default). <A NAME="1006294"></A></LI>

<LI>TOP aligns the text with the cell's top. </LI>
</UL>
</UL>

<H2>TITLE (document title) </H2>

<P><A NAME="1006303"></A>The TITLE tag specifies the title of the document.
Generally this title appears in the title bar of the browser window. In
addition, the title can be used by automated web search tools to locate
an applicable document. If a title is not provided, by default the filename
or URL of the document is displayed in the title bar. </P>

<P><A NAME="Syntax"></A><A NAME="1006304"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006305"></A><TT>&lt;TITLE&gt;...&lt;/TITLE&gt;</TT></P>

VALIGN=&quot;BASELINE&quot;|&quot;BOTTOM&quot;|&quot;MIDDLE&quot;|&quot;TOP&quot;
<BR>
&gt; <BR>
... <BR>
&lt;/TR&gt;</TT></P>

<LI>BOTTOM aligns the text with the cell's bottom. <A NAME="1006326"></A></LI>

<LI>MIDDLE centers the text within the cell (the default). <A NAME="1006327"></A></LI>

<H2>UL (unordered list) </H2>

<P><A NAME="1006343"></A>The UL tag defines an unordered list. These items,
each begun by the &lt;LI&gt; tag, can contain multiple paragraphs. Just
separate the paragraphs with the P paragraph tag. </P>

<P><A NAME="Syntax"></A><A NAME="1075136"></A></P>

<H4>Syntax </H4>

<P><A NAME="1075137"></A><TT>&lt;UL TYPE=&quot;CIRCLE&quot;|&quot;DISC&quot;|&quot;SQUARE&quot;&gt;</TT></P>

<BLOCKQUOTE></BLOCKQUOTE>

<P><A NAME="1075139"></A><I>TYPE </I>defines the type of bullet used for
each list item, depending on the type of list the item is in: <B><I>Navigator
1.1</I></B> </P>

<UL>
<UL>
<P><A NAME="1006347"></A></P>

<LI>CIRCLE a hollow bullet. <A NAME="1006348"></A></LI>

<LI>DISC a solid round bullet (Netscape Navigator default). <A NAME="1006349"></A></LI>

<LI>SQUARE a square bullet. </LI>
</UL>
</UL>

<H2>WBR (word break) </H2>

<P><A NAME="1084347"></A></P>

<BLOCKQUOTE>
<P><B><I>Navigator 1.1</I></B> </P>
</BLOCKQUOTE>

<P><A NAME="1075159"></A>The WBR tag marks a spot where a line break can
take place. It is advisory, as contrasted with the BR and NOBR tags. </P>

<P><A NAME="1006355"></A>The WBR tag does not require a closing tag. </P>

<P><A NAME="Syntax"></A><A NAME="1006356"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006357"></A><TT>&lt;WBR&gt; </TT></P>

<P><A NAME="Example"></A><A NAME="1006358"></A></P>

<H4>Example </H4>

<P><A NAME="1051573"></A></P>

<PRE><TT>&lt;NOBR&gt;

Line breaks are not ordinarily inserted into the text contained within a

&amp;lt;NOBR&amp;gt; block, which can produce some awkwardly long lines.

&lt;WBR&gt;

If the text contains a &amp;lt;WBR&amp;gt; tag, however, it marks a location
where the insertion of a line break is permitted.

&lt;/NOBR&gt;</TT>
</PRE>

<H2>XMP (sequence of literal characters) </H2>

<P><A NAME="1006365"></A>The XMP tag defines a sequence of literal characters,
such as example text. The text is displayed in the fixed-width font, as
determined in Options|General Preferences. Netscape Navigator ignores all
HTML tags within the scope of the XMP tag.</P>

<P><A NAME="Syntax"></A><A NAME="1006366"></A></P>

<H4>Syntax </H4>

<P><A NAME="1006367"></A>&lt;XMP&gt;...&lt;/XMP&gt;</P>

<P><A NAME="Example"></A><A NAME="1006368"></A></P>

<H4>Example </H4>

<P><A NAME="1006370"></A></P>

<PRE><TT>&lt;XMP&gt;

The &lt;XMP&gt; tag is similar to the &lt;PRE&gt; tag except that HTML tags inside
an &lt;XMP&gt; block are displayed rather than interpreted.

&lt;/XMP&gt;</TT>
